# Crustvale 1.0 TEST
Native Java/Canvas Android 8+ 4x4 Sandwich Sudoku variant.

Fill each row, column and bold 2x2 box with 1, 2, 3 and 4 exactly once. Each edge clue is the sum of digits strictly between 1 and 4 in that row or column. Exclude both ends. Adjacent 1 and 4 give a sum of zero. Gold digits are fixed. Tap other tiles to cycle 1, 2, 3, 4, blank. Twelve unique 4x4 sum-pattern boards have twelve distinct solutions and one to four fixed digits each.

Saved crust palette and fixed-digit marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Python enumeration finds all 288 completed 4x4 Sudoku grids. A Java ordered-toggle and group-set oracle checks all 288 completions plus 20000 mutated arrays per board against production endpoint-index sums and pairwise digit checks, confirming one solution each. Fixed cells, bounds, range, array length, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Shared numeric Latin-grid backbone with Orderfern, Copperdot and Towerveil is disclosed. This uses sums strictly between the smallest and largest digit instead of inequality, dot-pair or skyline visibility tests, and adds 2x2 boxes.
